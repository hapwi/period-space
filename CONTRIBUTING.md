# Contributing

period-space is currently maintainer-led. Bug reports and suggestions are welcome, but pull requests are limited to trusted contributors while the project is young.

## Pull requests

Pull requests are checked with [Vouch](https://github.com/mitchellh/vouch). Repository collaborators and contributors listed in [`.github/VOUCHED.td`](.github/VOUCHED.td) are allowed. Pull requests from other accounts are closed automatically.

Being unvouched is not a judgment about you or your work. It only means the project is not accepting unsolicited code from your account yet.

## Reporting a bug

Open an issue with:

- your Linux distribution and desktop environment
- the output of `period-space status`
- what you expected to happen
- what happened instead

Do not include passwords, tokens, or other private information.

## Trusted contributors

The repository owner decides when to trust another contributor. To grant access, add their GitHub username to `.github/VOUCHED.td`:

```text
github:username reason for vouching
```
